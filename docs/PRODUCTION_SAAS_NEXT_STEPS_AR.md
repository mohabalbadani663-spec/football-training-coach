# CoachIQ — الخطوة التالية

الترتيب المقترح بعد هذه النسخة:

1. تنفيذ `supabase/saas_migration.sql`.
2. تسجيل Coach جديد والتأكد من إنشاء Academy + Subscription + Team تلقائيًا.
3. إنشاء Player ثم إدخاله عبر دعوة البريد أو رمز الفريق.
4. اختبار أن Player يرى حصص فريقه فقط.
5. اختبار أن Coach A لا يستطيع قراءة أو تعديل بيانات Coach B.
6. اختبار إنشاء حصة واختيار فريق محدد ثم تعديلها لاحقًا.
7. إكمال الخطة الأسبوعية لتصبح مرتبطة بقاعدة البيانات بدل البيانات الثابتة.
8. إضافة إدارة الأكاديمية والفِرق المتعددة.
9. إضافة الاشتراكات والدفع بعد تثبيت المنتج الأساسي.
10. تجهيز Android signing وGoogle Play وPrivacy/Data Safety.
